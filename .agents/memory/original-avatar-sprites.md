---
name: Original avatar sprites
description: Lessons for generating and cropping original Little Nest character sheets.
---

When generating character sheets, inspect the complete sheet and a contact sheet of sample crops before processing every avatar. Image generation may ignore a requested aspect ratio or produce incomplete, uneven rows; only use confirmed complete panels and keep the picker count matched to the usable assets.

**Why:** Generated avatar sheets returned square canvases despite portrait layout prompts, and some lower-row crops cut across characters.

**How to apply:** For future avatar collections, verify panel boundaries and completeness first. If the available count changes, preserve old profile selections with an explicit ID remap.
